# 🎮 寶可夢注音・手寫練習表

讓小朋友看著喜歡的寶可夢，練習注音符號和漢字手寫的 A4 練習表。免費、非商業的親子學習資源。

**其他語言 / Other Languages:** [English](docs/i18n/README_en.md) | [日本語](docs/i18n/README_ja.md)

## 👉 [開啟練習表網站](https://tk009999.github.io/pokemon-phonetic-practice/)

搜尋寶可夢 → 點選想練習的 → 列印注音或手寫練習表。不用安裝任何東西。

| 練習表 | 內容 |
|--------|------|
| 🎮 注音練習表 | 看圖片和名稱，填寫注音符號 |
| ✏️ 手寫練習表 | 楷書範字、虛線字描寫、空白格，附運筆描線暖身頁 |

收錄全國圖鑑 #001–#1025（第一～第九世代）。想一次印整個世代，請見[各世代練習表](docs/DOWNLOADS.md)。

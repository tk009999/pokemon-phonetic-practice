# 🖨️ 列印與轉存 PDF

1. 開啟練習表（網站上按列印鈕，或開啟[各世代練習表](DOWNLOADS.md)的預覽），等所有寶可夢圖片載入完成
2. 按 `Ctrl + P`（Mac 為 `⌘ + P`）
3. 依下表設定後，按「列印」或「儲存」

| 設定 | 建議值 |
|------|--------|
| 目的地 | 印表機，或「儲存為 PDF」 |
| 紙張大小 | A4 |
| 方向 | 橫向 |
| 邊界 | 最小 |
| 背景圖形 | ✅ 勾選（保留邊框和底色） |
| 色彩 | 彩色 |

<details>
<summary>各瀏覽器「儲存為 PDF」的位置</summary>

| 瀏覽器 | 操作 |
|--------|------|
| Chrome / Edge | 目的地選「儲存為 PDF」 |
| Firefox | 目的地選「儲存為 PDF」或「Microsoft Print to PDF」 |
| Safari | 左下角「PDF」選單 →「儲存為 PDF」 |

</details>
